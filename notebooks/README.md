# Notebooks

This folder contains the Jupyter Notebooks used throughout the Enterprise Data Quality & Governance project.

## Notebooks

| Notebook                                     | Description                                            |
| -------------------------------------------- | ------------------------------------------------------ |
| `01_data_profiling.ipynb`                    | Exploratory profiling and understanding of the dataset |
| `02_data_quality_assessment.ipynb`           | Definition and assessment of Data Quality Rules        |
| `03_data_quality_issues_findings.ipynb`      | Analysis and documentation of quality findings         |
| `04_data_quality_validation_framework.ipynb` | Development of a reusable validation structure         |

Each notebook corresponds to a stage of the project and contains the analysis, Python code, and results for that stage.
